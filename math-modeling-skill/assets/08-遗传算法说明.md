# 遗传算法 (Genetic Algorithm, GA) 说明文档

## 概述

遗传算法是一种模拟自然选择和遗传机制的随机搜索优化算法，由 Holland 于 1975 年提出。它通过模拟生物进化过程中的选择、交叉、变异等操作，在解空间中搜索最优解。GA 特别适用于处理非线性、多峰值、离散和不可微的优化问题。

---

## 算法原理

### 核心思想

将问题的候选解编码为"染色体"（个体），通过适应度函数评价个体优劣，模拟"优胜劣汰"的自然选择过程，经过多代进化得到最优解。

### 算法流程

```
1. 初始化种群（随机生成 N 个个体）
2. 计算每个个体的适应度
3. 选择操作（轮盘赌/锦标赛选择）
4. 交叉操作（单点/多点/均匀交叉）
5. 变异操作（位翻转变异/高斯变异）
6. 精英保留（将最优个体直接复制到下一代）
7. 判断是否满足终止条件（最大代数/收敛阈值）
8. 若不满足，返回步骤 2；否则输出最优解
```

### 数学表示

**适应度函数**：$F(x) = f(x)$ （最大化问题）或 $F(x) = 1 / (1 + f(x))$ （最小化问题）

**选择概率**（轮盘赌）：$P_i = \frac{F_i}{\sum_{j=1}^N F_j}$

**交叉操作**（单点交叉）：在染色体上随机选择一个交叉点，交换两个父代染色体在交叉点后的部分

**变异操作**（位翻转）：对染色体上的每个基因位以概率 $p_m$ 进行翻转（0→1 或 1→0）

## Python 实现模板

```python
import numpy as np

def genetic_algorithm(
    fitness_func,        # 适应度函数
    n_vars,              # 决策变量数量
    bounds,              # 变量范围 [(low, high), ...]
    pop_size=50,         # 种群大小
    max_gen=100,         # 最大代数
    crossover_rate=0.8,  # 交叉概率
    mutation_rate=0.05,  # 变异概率
    elite_ratio=0.1,     # 精英比例
    tol=1e-6,            # 收敛容忍度
    patience=10,         # 早停耐心值
):
    """遗传算法求解无约束最大化问题"""
    n_elite = max(1, int(pop_size * elite_ratio))
    n_vars = len(bounds)
    dim = n_vars
    
    # 初始化种群
    pop = np.random.rand(pop_size, dim)
    for i in range(dim):
        pop[:, i] = pop[:, i] * (bounds[i][1] - bounds[i][0]) + bounds[i][0]
    
    best_fitness_history = []
    best_individual = None
    best_fitness = -np.inf
    no_improve = 0
    
    for gen in range(max_gen):
        # 计算适应度
        fitness = np.array([fitness_func(ind) for ind in pop])
        
        # 更新最优解
        current_best = fitness.max()
        if current_best > best_fitness + tol:
            best_fitness = current_best
            best_individual = pop[fitness.argmax()].copy()
            no_improve = 0
        else:
            no_improve += 1
        
        best_fitness_history.append(best_fitness)
        
        # 早停判断
        if no_improve >= patience:
            converge_status = "已收敛"
            break
        
        # 选择
        fitness_norm = fitness - fitness.min() + 1e-10
        probs = fitness_norm / fitness_norm.sum()
        idx = np.random.choice(pop_size, size=pop_size - n_elite, p=probs)
        selected = pop[idx]
        
        # 交叉
        offspring = []
        for i in range(0, len(selected), 2):
            if i + 1 < len(selected) and np.random.rand() < crossover_rate:
                point = np.random.randint(1, dim)
                child1 = np.concatenate([selected[i][:point], selected[i+1][point:]])
                child2 = np.concatenate([selected[i+1][:point], selected[i][point:]])
                offspring.extend([child1, child2])
            else:
                offspring.extend([selected[i], selected[i+1] if i+1 < len(selected) else selected[i]])
        
        # 变异
        for i in range(len(offspring)):
            if np.random.rand() < mutation_rate:
                j = np.random.randint(dim)
                offspring[i][j] = np.random.rand() * (bounds[j][1] - bounds[j][0]) + bounds[j][0]
        
        # 精英保留
        elite_idx = fitness.argsort()[-n_elite:]
        pop = np.vstack([pop[elite_idx], np.array(offspring[:pop_size - n_elite])])
    
    else:
        converge_status = "未收敛（达到最大迭代次数）"
    
    return {
        "best_individual": best_individual,
        "best_fitness": best_fitness,
        "fitness_history": best_fitness_history,
        "converge_status": converge_status,
        "n_generations": gen + 1,
    }
```

## 参数调优建议

| 参数 | 推荐范围 | 说明 |
|------|----------|------|
| 种群大小 | 30~100 | 问题越复杂，种群越大 |
| 交叉概率 | 0.6~0.9 | 过高会破坏优良基因 |
| 变异概率 | 0.01~0.1 | 过高退化为随机搜索 |
| 精英比例 | 0.05~0.2 | 过高会早熟收敛 |
| 最大代数 | 100~1000 | 视问题复杂度而定 |

## 适用范围

| 问题类型 | 适用性 | 说明 |
|----------|--------|------|
| 连续优化 | ✅ 适用 | 需配合实数编码和模拟二进制交叉（SBX） |
| 离散优化 | ✅ 适用 | 天然适合二进制编码 |
| 组合优化 | ✅ 适用 | TSP、背包问题等经典应用 |
| 多目标优化 | ✅ 适用 | 配合 NSGA-II、MOEA/D 等框架 |
| 约束优化 | ✅ 适用 | 配合罚函数法或约束支配原则 |

## 在数学建模中的应用

- **调度优化**：生产调度、考试时间安排
- **路径规划**：TSP、VRP 问题
- **参数优化**：模型参数反演、神经网络权重优化
- **特征选择**：高维数据的特征子集选择
- **布局优化**：设施选址、货物摆放
