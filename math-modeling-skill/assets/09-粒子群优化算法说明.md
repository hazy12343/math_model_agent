# 粒子群优化 (Particle Swarm Optimization, PSO) 说明文档

## 概述

粒子群优化算法由 Kennedy 和 Eberhart 于 1995 年提出，灵感来源于鸟群觅食行为。PSO 通过个体最优（pbest）和全局最优（gbest）引导粒子在解空间中飞行，是一种简单高效的群体智能优化算法。

---

## 算法原理

### 核心思想

每个粒子代表解空间中的一个候选解，粒子具有位置和速度两个属性。粒子根据自身历史最优位置和群体历史最优位置更新飞行方向，逐步逼近全局最优。

### 速度更新公式

$$v_i^{t+1} = w \cdot v_i^t + c_1 r_1 (pbest_i - x_i^t) + c_2 r_2 (gbest - x_i^t)$$

其中：
- $w$：惯性权重，控制全局搜索和局部搜索的平衡
- $c_1$：个体学习因子，粒子向自身最优靠近的权重
- $c_2$：社会学习因子，粒子向全局最优靠近的权重
- $r_1, r_2$：[0,1] 之间的随机数

### 位置更新公式

$$x_i^{t+1} = x_i^t + v_i^{t+1}$$

### 算法流程

```
1. 初始化粒子群（位置和速度随机初始化）
2. 计算每个粒子的适应度
3. 更新个体最优 pbest 和全局最优 gbest
4. 更新粒子的速度和位置
5. 判断是否满足终止条件
6. 若不满足，返回步骤 2；否则输出最优解
```

## Python 实现模板

```python
import numpy as np

def particle_swarm_optimization(
    fitness_func,        # 适应度函数
    bounds,              # 变量范围 [(low, high), ...]
    n_particles=30,      # 粒子数量
    max_iter=100,        # 最大迭代次数
    w=0.7,               # 惯性权重
    w_start=0.9,         # 初始惯性权重（线性递减时）
    w_end=0.4,           # 最终惯性权重（线性递减时）
    c1=1.5,              # 个体学习因子
    c2=1.5,              # 社会学习因子
    clamp_speed=True,    # 是否限制速度
    tol=1e-6,            # 收敛容忍度
    patience=15,         # 早停耐心值
):
    """粒子群优化算法求解无约束最大化问题"""
    dim = len(bounds)
    
    # 初始化粒子位置
    positions = np.random.rand(n_particles, dim)
    for i in range(dim):
        positions[:, i] = positions[:, i] * (bounds[i][1] - bounds[i][0]) + bounds[i][0]
    
    # 初始化粒子速度
    velocities = np.random.randn(n_particles, dim) * 0.1
    for i in range(dim):
        velocities[:, i] *= (bounds[i][1] - bounds[i][0])
    
    # 初始化个体最优
    pbest_positions = positions.copy()
    pbest_fitness = np.array([fitness_func(p) for p in positions])
    
    # 初始化全局最优
    gbest_idx = pbest_fitness.argmax()
    gbest_position = pbest_positions[gbest_idx].copy()
    gbest_fitness = pbest_fitness[gbest_idx]
    
    best_fitness_history = [gbest_fitness]
    no_improve = 0
    
    for iteration in range(max_iter):
        # 线性递减惯性权重
        w_current = w_start - (w_start - w_end) * iteration / max_iter
        
        # 更新速度
        r1 = np.random.rand(n_particles, dim)
        r2 = np.random.rand(n_particles, dim)
        
        velocities = (w_current * velocities +
                     c1 * r1 * (pbest_positions - positions) +
                     c2 * r2 * (gbest_position - positions))
        
        # 速度限制
        if clamp_speed:
            for i in range(dim):
                v_max = 0.5 * (bounds[i][1] - bounds[i][0])
                velocities[:, i] = np.clip(velocities[:, i], -v_max, v_max)
        
        # 更新位置
        positions = positions + velocities
        for i in range(dim):
            positions[:, i] = np.clip(positions[:, i], bounds[i][0], bounds[i][1])
        
        # 计算适应度
        fitness = np.array([fitness_func(p) for p in positions])
        
        # 更新个体最优
        improve_mask = fitness > pbest_fitness
        pbest_positions[improve_mask] = positions[improve_mask].copy()
        pbest_fitness[improve_mask] = fitness[improve_mask]
        
        # 更新全局最优
        current_best = pbest_fitness.max()
        if current_best > gbest_fitness + tol:
            gbest_fitness = current_best
            gbest_position = pbest_positions[pbest_fitness.argmax()].copy()
            no_improve = 0
        else:
            no_improve += 1
        
        best_fitness_history.append(gbest_fitness)
        
        # 早停判断
        if no_improve >= patience:
            converge_status = "已收敛"
            break
    else:
        converge_status = "未收敛（达到最大迭代次数）"
    
    return {
        "best_position": gbest_position,
        "best_fitness": gbest_fitness,
        "fitness_history": best_fitness_history,
        "converge_status": converge_status,
        "n_iterations": iteration + 1,
    }
```

## 参数调优建议

| 参数 | 推荐范围 | 说明 |
|------|----------|------|
| 粒子数量 | 20~50 | 问题越复杂，粒子越多 |
| 惯性权重 | 0.4~0.9 | 线性递减策略：0.9→0.4 |
| 个体学习因子 c1 | 1.0~2.0 | 过大导致局部搜索过度 |
| 社会学习因子 c2 | 1.0~2.0 | 过大导致早熟收敛 |
| 速度限制 | 0.5×(ub-lb) | 防止粒子飞出边界 |

## 与遗传算法的对比

| 对比项 | PSO | GA |
|--------|-----|-----|
| 编码方式 | 实数编码（天然） | 二进制/实数编码 |
| 搜索机制 | 速度-位置更新 | 选择-交叉-变异 |
| 参数数量 | 较少（3~4个） | 较多（5~6个） |
| 收敛速度 | 较快 | 中等 |
| 全局搜索能力 | 中等 | 较强 |
| 实现复杂度 | 简单 | 中等 |
