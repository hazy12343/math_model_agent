# 模拟退火 (Simulated Annealing, SA) 说明文档

## 概述

模拟退火算法由 Kirkpatrick 等人于 1983 年提出，灵感来源于固体退火过程。SA 通过模拟高温下粒子无序运动到低温下有序排列的过程，以一定概率接受劣解，从而跳出局部最优，是一种经典的全局优化算法。

---

## 算法原理

### 核心思想

从高温开始，随着温度降低，算法在解空间中随机搜索。高温时以较高概率接受劣解（探索全局），低温时只接受优解（局部收敛）。接受劣解的概率由 Metropolis 准则控制。

### Metropolis 准则

接受新解的概率：
$$P(\text{accept}) = \begin{cases} 1, & \Delta f \leq 0 \\ e^{-\Delta f / T}, & \Delta f > 0 \end{cases}$$

其中 $\Delta f = f(x_{new}) - f(x_{current})$ 为目标函数变化量，$T$ 为当前温度。

### 温度衰减函数

常用指数衰减：$T_{k+1} = \alpha \cdot T_k$，其中 $\alpha \in (0.8, 0.99)$

### 算法流程

```
1. 初始化：初始温度 T0，终止温度 T_end，衰减系数 α
2. 生成初始解 x_current，计算目标函数值 f_current
3. 对当前温度 T：
   a. 在当前解附近生成新解 x_new
   b. 计算新解的目标函数值 f_new
   c. 计算 Δf = f_new - f_current
   d. 若 Δf < 0，接受新解
   e. 否则以概率 exp(-Δf/T) 接受新解
   f. 重复 a-e 共 L 次（马尔可夫链长度）
4. 降温：T = α * T
5. 若 T > T_end，返回步骤 3；否则输出最优解
```

## Python 实现模板

```python
import numpy as np

def simulated_annealing(
    objective_func,      # 目标函数（最小化）
    bounds,              # 变量范围 [(low, high), ...]
    T0=1000,             # 初始温度
    T_end=1e-6,          # 终止温度
    alpha=0.95,          # 温度衰减系数
    n_iter_per_T=50,     # 每个温度的迭代次数（马尔可夫链长度）
    initial_solution=None,  # 初始解
    tol=1e-6,            # 收敛容忍度
):
    """模拟退火算法求解无约束最小化问题"""
    dim = len(bounds)
    
    # 初始化当前解
    if initial_solution is not None:
        x_current = np.array(initial_solution, dtype=float)
    else:
        x_current = np.array([np.random.uniform(b[0], b[1]) for b in bounds])
    
    f_current = objective_func(x_current)
    
    x_best = x_current.copy()
    f_best = f_current
    
    T = T0
    best_history = [f_best]
    temperature_history = [T]
    
    while T > T_end:
        for _ in range(n_iter_per_T):
            # 生成新解（在当前解附近随机扰动）
            x_new = x_current + np.random.randn(dim) * 0.1 * (bounds[0][1] - bounds[0][0])
            for i in range(dim):
                x_new[i] = np.clip(x_new[i], bounds[i][0], bounds[i][1])
            
            f_new = objective_func(x_new)
            delta_f = f_new - f_current
            
            # Metropolis 准则
            if delta_f < 0 or np.random.rand() < np.exp(-delta_f / max(T, 1e-10)):
                x_current = x_new.copy()
                f_current = f_new
                
                if f_current < f_best:
                    x_best = x_current.copy()
                    f_best = f_current
        
        # 降温
        T *= alpha
        best_history.append(f_best)
        temperature_history.append(T)
        
        # 收敛判断
        if len(best_history) >= 10:
            recent_improvement = abs(best_history[-1] - best_history[-5])
            if recent_improvement < tol:
                converge_status = "已收敛"
                break
    else:
        converge_status = "未收敛（达到终止温度）"
    
    return {
        "best_position": x_best,
        "best_value": f_best,
        "fitness_history": best_history,
        "temperature_history": temperature_history,
        "converge_status": converge_status,
        "final_temperature": T,
    }
```

## 参数调优建议

| 参数 | 推荐范围 | 说明 |
|------|----------|------|
| 初始温度 T0 | 100~10000 | 越高全局搜索能力越强 |
| 终止温度 T_end | 1e-3~1e-8 | 越低解越精确但耗时 |
| 衰减系数 α | 0.85~0.99 | 越接近 1 降温越慢 |
| 链长 n_iter | 50~200 | 越长搜索越充分 |

---

## 与遗传算法、粒子群的对比

| 对比项 | SA | GA | PSO |
|--------|-----|-----|-----|
| 搜索机制 | 单点随机游走 | 群体进化 | 群体飞行 |
| 跳出局部最优 | Metropolis 准则 | 变异操作 | 速度惯性 |
| 收敛速度 | 慢 | 中等 | 快 |
| 全局搜索能力 | 强 | 强 | 中等 |
| 参数数量 | 少（3~4个） | 多（5~6个） | 中等（4~5个） |
| 证明收敛性 | 是（概率 1） | 是（精英保留时） | 否 |

## 在数学建模中的应用
