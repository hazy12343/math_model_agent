# 假设检验 (Hypothesis Testing) 说明文档

## 概述

假设检验是统计推断的核心方法之一，用于根据样本数据对总体参数或分布做出判断。在数学建模中，假设检验广泛用于验证模型假设、比较方案差异、分析数据特征等场景。

---

## 1. t 检验 (t-Test)

### 原理

t 检验用于检验两个总体的均值是否存在显著差异，适用于小样本（n < 30）且总体方差未知的情况。

### 适用场景

| 检验类型 | 公式 | 适用场景 |
|----------|------|----------|
| 单样本 t 检验 | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ | 样本均值与已知总体均值比较 |
| 独立样本 t 检验 | $t = \frac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{1/n_1+1/n_2}}$ | 两组独立样本均值比较 |
| 配对样本 t 检验 | $t = \frac{\bar{d}}{s_d/\sqrt{n}}$ | 配对数据的均值差异检验 |

### Python 实现

```python
import numpy as np
from scipy import stats

def t_test_one_sample(sample, mu0=0, alpha=0.05):
    """单样本 t 检验"""
    t_stat, p_value = stats.ttest_1samp(sample, mu0)
    reject = p_value < alpha
    return {
        "t_statistic": t_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "拒绝原假设" if reject else "无法拒绝原假设",
        "confidence_interval": stats.t.interval(
            0.95, df=len(sample)-1,
            loc=np.mean(sample),
            scale=stats.sem(sample)
        )
    }

def t_test_two_sample(sample1, sample2, equal_var=True, alpha=0.05):
    """独立样本 t 检验"""
    t_stat, p_value = stats.ttest_ind(sample1, sample2, equal_var=equal_var)
    reject = p_value < alpha
    return {
        "t_statistic": t_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "两组均值存在显著差异" if reject else "两组均值无显著差异",
        "mean_diff": np.mean(sample1) - np.mean(sample2),
    }

def t_test_paired(sample1, sample2, alpha=0.05):
    """配对样本 t 检验"""
    t_stat, p_value = stats.ttest_rel(sample1, sample2)
    reject = p_value < alpha
    return {
        "t_statistic": t_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "配对数据存在显著差异" if reject else "配对数据无显著差异",
    }
```

## 2. F 检验 (F-Test)

### 原理

F 检验用于比较两个总体的方差是否存在显著差异，也用于方差分析（ANOVA）中检验多个组均值是否相等。

### 方差齐性检验

$$F = \frac{s_1^2}{s_2^2} \sim F(n_1-1, n_2-1)$$

### 单因素方差分析 (ANOVA)

| 变异来源 | 平方和 | 自由度 | 均方 | F 值 |
|----------|--------|--------|------|------|
| 组间 | SSB | k-1 | MSB = SSB/(k-1) | F = MSB/MSW |
| 组内 | SSW | N-k | MSW = SSW/(N-k) | |
| 总变异 | SST | N-1 | | |

### Python 实现

```python
from scipy import stats

def f_test_variance(sample1, sample2, alpha=0.05):
    """方差齐性 F 检验"""
    f_stat = np.var(sample1, ddof=1) / np.var(sample2, ddof=1)
    df1 = len(sample1) - 1
    df2 = len(sample2) - 1
    p_value = 2 * min(stats.f.cdf(f_stat, df1, df2),
                       1 - stats.f.cdf(f_stat, df1, df2))
    reject = p_value < alpha
    return {
        "f_statistic": f_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "方差存在显著差异" if reject else "方差无显著差异",
    }

def anova_one_way(*groups, alpha=0.05):
    """单因素方差分析"""
    f_stat, p_value = stats.f_oneway(*groups)
    reject = p_value < alpha
    return {
        "f_statistic": f_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "各组均值存在显著差异" if reject else "各组均值无显著差异",
    }
```

## 3. 卡方检验 (Chi-Square Test)

### 原理

卡方检验用于检验分类变量之间的关联性，以及实际频数与期望频数是否一致。

### 独立性检验

$$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

### 拟合优度检验

$$\chi^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i}$$

### Python 实现

```python
from scipy import stats

def chi_square_independence(contingency_table, alpha=0.05):
    """卡方独立性检验"""
    chi2_stat, p_value, dof, expected = stats.chi2_contingency(contingency_table)
    reject = p_value < alpha
    return {
        "chi2_statistic": chi2_stat,
        "p_value": p_value,
        "degrees_of_freedom": dof,
        "reject_null": reject,
        "conclusion": "变量之间存在关联" if reject else "变量之间独立",
        "expected_frequencies": expected,
    }

def chi_square_goodness_of_fit(observed, expected=None, alpha=0.05):
    """卡方拟合优度检验"""
    if expected is None:
        # 均匀分布
        expected = np.ones_like(observed) * np.mean(observed)
    chi2_stat, p_value = stats.chisquare(observed, f_exp=expected)
    reject = p_value < alpha
    return {
        "chi2_statistic": chi2_stat,
        "p_value": p_value,
        "reject_null": reject,
        "conclusion": "分布与期望不一致" if reject else "分布与期望一致",
    }
```

## 在数学建模中的应用

- **模型比较**：不同模型的预测结果是否存在显著差异
- **参数显著性**：回归系数是否显著不为零
- **数据预处理**：异常值检测、正态性检验
- **方案评价**：不同方案的效果是否存在显著差异
- **敏感性分析**：参数变化对结果的影响是否显著
