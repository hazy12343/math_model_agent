# 回归分析 (Regression Analysis) 说明文档

## 概述

回归分析是研究变量之间相关关系的统计方法，用于建立预测模型、分析影响因素、控制混杂变量等。在数学建模中，回归分析是最常用的数据分析工具之一。

---

## 1. 线性回归 (Linear Regression)

### 原理

线性回归假设因变量 $y$ 与自变量 $x_1, x_2, ..., x_p$ 之间存在线性关系：

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p + \varepsilon$$

### 参数估计（最小二乘法）

$$\hat{\beta} = (X^T X)^{-1} X^T y$$

### 模型评价指标

| 指标 | 公式 | 说明 |
|------|------|------|
| $R^2$ | $1 - \frac{SS_{res}}{SS_{tot}}$ | 解释变异比例 |
| 调整 $R^2$ | $1 - \frac{SS_{res}/(n-p-1)}{SS_{tot}/(n-1)}$ | 考虑自变量数量 |
| RMSE | $\sqrt{\frac{1}{n}\sum(y_i - \hat{y}_i)^2}$ | 均方根误差 |
| MAE | $\frac{1}{n}\sum|y_i - \hat{y}_i|$ | 平均绝对误差 |

### Python 实现

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import r2_score, mean_squared_error, mean_absolute_error
from scipy import stats

def linear_regression_analysis(X, y, add_intercept=True):
    """完整线性回归分析（含统计推断）"""
    if add_intercept:
        X = np.column_stack([np.ones(len(X)), X])
    
    # 最小二乘估计
    beta = np.linalg.lstsq(X, y, rcond=None)[0]
    y_pred = X @ beta
    residuals = y - y_pred
    
    n, p = X.shape
    sigma2 = np.sum(residuals**2) / (n - p)
    cov_beta = sigma2 * np.linalg.inv(X.T @ X)
    se_beta = np.sqrt(np.diag(cov_beta))
    t_stats = beta / se_beta
    p_values = 2 * (1 - stats.t.cdf(np.abs(t_stats), n - p))
    
    # 模型评价
    r2 = r2_score(y, y_pred)
    adj_r2 = 1 - (1 - r2) * (n - 1) / (n - p)
    rmse = np.sqrt(mean_squared_error(y, y_pred))
    mae = mean_absolute_error(y, y_pred)
    
    # F 检验
    ssr = np.sum((y_pred - y.mean())**2)
    sse = np.sum(residuals**2)
    f_stat = (ssr / (p - 1)) / (sse / (n - p))
    f_p_value = 1 - stats.f.cdf(f_stat, p - 1, n - p)
    
    return {
        "coefficients": beta,
        "std_errors": se_beta,
        "t_statistics": t_stats,
        "p_values": p_values,
        "r_squared": r2,
        "adj_r_squared": adj_r2,
        "rmse": rmse,
        "mae": mae,
        "f_statistic": f_stat,
        "f_p_value": f_p_value,
        "residuals": residuals,
    }
```

## 2. 多项式回归 (Polynomial Regression)

### 原理

多项式回归将自变量的高次项作为新特征引入线性回归模型：

$$y = \beta_0 + \beta_1 x + \beta_2 x^2 + \cdots + \beta_d x^d + \varepsilon$$

### 实现

```python
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

def polynomial_regression(X, y, degree=2, alpha=0.05):
    """多项式回归"""
    from sklearn.linear_model import LinearRegression
    
    # 构建多项式特征
    poly = PolynomialFeatures(degree=degree, include_bias=True)
    X_poly = poly.fit_transform(X.reshape(-1, 1))
    
    # 拟合
    model = LinearRegression(fit_intercept=False)
    model.fit(X_poly, y)
    y_pred = model.predict(X_poly)
    
    # 评价
    r2 = r2_score(y, y_pred)
    adj_r2 = 1 - (1 - r2) * (len(y) - 1) / (len(y) - degree - 1)
    
    return {
        "coefficients": model.coef_,
        "intercept": 0,  # included in coefficients
        "feature_names": poly.get_feature_names_out(),
        "r_squared": r2,
        "adj_r_squared": adj_r2,
        "y_pred": y_pred,
        "degree": degree,
    }
```

## 3. 岭回归 (Ridge Regression)

### 原理

岭回归通过在损失函数中加入 L2 正则化项，解决多重共线性问题和过拟合：

$$\hat{\beta} = \arg\min \left\{ \sum_{i=1}^n (y_i - \beta_0 - \sum_{j=1}^p x_{ij}\beta_j)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}$$

### 解析解

$$\hat{\beta} = (X^T X + \lambda I)^{-1} X^T y$$

### 实现

```python
from sklearn.linear_model import Ridge, RidgeCV

def ridge_regression(X, y, alpha=1.0):
    """岭回归（固定正则化系数）"""
    model = Ridge(alpha=alpha)
    model.fit(X, y)
    y_pred = model.predict(X)
    return {
        "coefficients": model.coef_,
        "intercept": model.intercept_,
        "r_squared": r2_score(y, y_pred),
        "y_pred": y_pred,
    }

def ridge_regression_cv(X, y, alphas=None):
    """岭回归（交叉验证选择最优 λ）"""
    if alphas is None:
        alphas = np.logspace(-4, 4, 50)
    model = RidgeCV(alphas=alphas, scoring='r2')
    model.fit(X, y)
    y_pred = model.predict(X)
    return {
        "best_alpha": model.alpha_,
        "coefficients": model.coef_,
        "intercept": model.intercept_,
        "r_squared": r2_score(y, y_pred),
        "cv_scores": model.cv_values_,
        "y_pred": y_pred,
    }
```

## 模型选择与比较

### 三种回归对比

| 特性 | 线性回归 | 多项式回归 | 岭回归 |
|------|----------|------------|--------|
| 关系假设 | 线性 | 多项式 | 线性+正则化 |
| 过拟合风险 | 低 | 高（阶数高时） | 低 |
| 多重共线性 | 敏感 | 敏感 | 不敏感 |
| 可解释性 | 高 | 中 | 低 |
| 预测精度 | 一般 | 高（合适阶数时） | 高 |

### 回归诊断

```python
def regression_diagnostics(model_result, X, y):
    """回归诊断：残差分析、正态性检验、异方差检验"""
    residuals = model_result["residuals"]
    y_pred = model_result.get("y_pred", None)
    if y_pred is None:
        y_pred = X @ model_result["coefficients"]
    
    # 1. 残差正态性检验（Shapiro-Wilk）
    shapiro_stat, shapiro_p = stats.shapiro(residuals)
    
    # 2. 残差自相关检验（Durbin-Watson）
    dw = np.sum(np.diff(residuals)**2) / np.sum(residuals**2)
    
    # 3. 异方差检验（Breusch-Pagan）
    residuals_sq = residuals**2
    bp_model = LinearRegression().fit(X, residuals_sq)
    bp_r2 = bp_model.score(X, residuals_sq)
    bp_stat = len(y) * bp_r2
    bp_p = 1 - stats.chi2.cdf(bp_stat, X.shape[1] - 1)
    
    return {
        "shapiro_p_value": shapiro_p,
        "residuals_normal": shapiro_p > 0.05,
        "durbin_watson": dw,
        "no_autocorrelation": 1.5 < dw < 2.5,
        "breusch_pagan_p": bp_p,
        "homoscedastic": bp_p > 0.05,
    }
```

## 在数学建模中的应用

- **预测建模**：销量预测、房价预测、气温预测
- **因素分析**：影响碳排放的关键因素识别
- **趋势分析**：时间序列趋势拟合
- **数据插值**：缺失数据填补
- **因果关系推断**：控制混杂变量后的因果效应估计
