# 论文写作规范

- 术语和符号严格服从 `术语表格.md`。
- 每段围绕一个明确论点，先给事实或推理，再解释其含义。
- 数值、单位、公式、图号、表号和引用前后一致。
- 不使用“专家认为”“效果显著”等无来源表述。
- 不用宣传性语言代替证据；创新点必须对应具体方法、实现和验证。
- 不虚构数据、实验、文献或官方要求。
- 两个模型得到相近结论时，如有比较价值，可如实保留并解释。
- 中文或英文表达服从目标竞赛和用户要求。

## LaTeX 公式格式规范

### 公式分隔符
- 行内公式：`$...$` 或 `\(...\)`
- 独立公式：`$$...$$` 或 `\[...\]`
- 长公式换行：`\begin{aligned}` 等环境

### 公式编号（必须）
- 所有独立公式必须编号 `(1)`、`(2)`、`(3)`...
- Markdown：`$$ ... \tag{1} $$`
- LaTeX：`\begin{equation} ... \label{eq:xxx} \end{equation}`
- 正文引用：由式(3)可得...

### 下标/上标中的文字
- 使用 `\mathrm{...}` 而非 `\text{...}`
- 正确：`\mathbf P^{\mathrm{drop}}_{j,k}`、`T_{\mathrm{cover},i}`
- 错误：`\mathbf P^{\text{drop}}_{j,k}`（`\text` 需要 amsmath，可移植性差）

### 分数
- 必须使用完整形式 `\frac{分子}{分母}`
- 正确：`\frac{1}{2}`、`\frac{\partial f}{\partial x}`
- 禁止：`\frac12`、`\frac1n`（不符合 LaTeX 规范）

### 范数/绝对值
- 范数：`\lVert ... \rVert` 或 `\left\| ... \right\|`
- 绝对值：`\lvert ... \rvert` 或 `\left| ... \right|`
- 禁止：`||x||`（双竖线间距不正确）

### 向量/矩阵
- 向量：`\mathbf{v}` 或 `\boldsymbol{v}`
- 矩阵：`\mathbf{A}` 或 `\boldsymbol{A}`
- 转置：`^{\mathsf{T}}` 或 `^{\top}`

### 常见符号
- 微分算子：`\mathrm{d}`
- 自然对数底：`\mathrm{e}`
- 虚数单位：`\mathrm{i}`
- 最大化/最小化：`\max_{x \in X}`、`\min_{x \in X}`

### 禁止模式
- ❌ `\frac12` → ✅ `\frac{1}{2}`
- ❌ `\text{xxx}` → ✅ `\mathrm{xxx}`
- ❌ `||x||` → ✅ `\lVert x \rVert`
- ❌ 独立公式不加编号
- ❌ 中文出现在数学模式中

## Word 转换

论文使用 Markdown + LaTeX 数学公式。生成 Word 文档只需一条 Pandoc 命令：

```bash
pandoc 完整论文.md -o 完整论文.docx --from markdown --to docx --mathjax
```

转换是自动的：`\mathbf` → Word 粗体、`\mathrm` → Word 正体、`\frac{}{}` → Word 分数、`\sum` → Word 求和。无需手动修改任何公式。
